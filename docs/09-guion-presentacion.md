## Texto guía

“PizIA es una aplicación web para facilitar la consulta del catálogo y el registro de pedidos de una pizzería. Su recomendador compara las preferencias con los ingredientes cargados, respeta exclusiones y presupuesto y muestra el motivo de cada sugerencia. El cliente puede explorar y pedir; el operador inicia sesión para mantener el catálogo y consultar pedidos. La aplicación usa Django y PostgreSQL. No procesa pagos ni integra un servicio generativo. Validamos el flujo con los casos de prueba y los resultados que mostramos en pantalla. Como mejora futura proponemos inventario, estados de preparación y pruebas con usuarios.”

No afirmes ejecuciones, resultados, despliegue, integrantes o aportes que el equipo no pueda mostrar. Cronometra un ensayo completo y reserva tiempo para que cada actor haga una operación real.
